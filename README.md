**Customer Sales Analysis Dashboard (Excel + MySQL)**


**📊 Project Overview**

Interactive Excel dashboard analyzing customer sales performance across multiple dimensions. The project uses MySQL for data storage and queries, and Excel for visualization and interactive dashboards. It demonstrates the complete workflow from data extraction → analysis → visualization → insights.

**🎯 Objectives**

Monthly sales & order trends
Men vs Women sales comparison
Top-performing states and cities
Customer demographics (age & gender)
Sales channel performance (Amazon, Flipkart, Myntra, etc.)
Membership-based sales analysis

**🛠️ Tools Used**

MySQL: Create tables, insert data, run queries, joins, and aggregations
Microsoft Excel: Pivot Tables & Charts, Slicers, Dashboard creation
Data Cleaning & Transformation

**📈 Key Insights**

✅ Women contribute more than Men in total sales
✅ 90%+ orders delivered successfully
✅ Top-performing states: Telangana, Karnataka, Tamil Nadu
✅ Top sales channels: Amazon & Myntra
✅ High-value customers usually have Gold or Platinum membership
